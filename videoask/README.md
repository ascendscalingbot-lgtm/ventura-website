# Ventura Ask

Standalone VideoAsk-style studio + live respondent player.

## Links

- Studio (admin): `/videoask/`
- Live respondent: `/videoask/?take=<id>`

Recordings and replies are stored in this browser (IndexedDB). Open the live link on the same device you recorded on.

## Admin flow

1. Mic + camera access
2. Hold REC to ask (or tap to start / tap to stop)
3. Pick how people answer (video, voice, text, multiple choice, yes/no)
4. Survey is live. Share the link or add more steps.
